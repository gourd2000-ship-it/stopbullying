# 학교폭력 상담 챗봇 '마음샘' 프로젝트 설계서 (PRD)

## 1. 프로젝트 개요
초등학교 중~고학년 학생들을 대상으로, 학교폭력이나 친구 관계의 어려움을 겪는 학생들에게 따뜻한 위로를 제공하고 선생님이 상황을 정확히 파악할 수 있도록 돕는 AI 상담 웹앱입니다.

## 2. 핵심 목표
1. **정서적 지원**: 학생들이 혼자 고민하지 않도록 따뜻한 공감과 지지를 제공합니다.
2. **정보 수집 및 요약**: 상담 교사가 후속 조치를 취할 수 있도록 필수 정보를 수집하고 요약 보고서를 생성합니다.
3. **안전 보장**: 긴급 상황(자해, 폭력 등) 감지 시 즉시 112 안내 및 어른의 개입을 유도합니다.
4. **보안성**: API 키 노출 방지를 위해 백엔드 프록시를 통해 안전하게 LLM을 사용합니다.

## 3. 시스템 아키텍처

### Frontend (Vite + React + TS)
- **역할**: 사용자 인터페이스, 클라이언트 상태 관리, 로컬 상담 기록 저장(MVP).
- **디자인**: 초등학생 눈높이에 맞춘 따뜻하고 부드러운 Vanilla CSS 디자인.
- **주요 페이지**:
  - `Landing`: 별명 입력 및 개인정보 처리 안내.
  - `Chat`: Gemini API 기반의 자연스러운 대화형 상담.
  - `Admin`: 비밀번호 보호된 상담 목록 및 상세 보고서 확인 페이지.

### Backend (Node.js + Express)
- **역할**: Gemini API 프록시, 시스템 프롬프트 관리, 데이터 요약 로직 수행.
- **보안**: API 키를 서버 환경 변수(`.env`)에서 관리하여 클라이언트에 노출되지 않도록 보호.
- **엔드포인트**:
  - `POST /api/chat`: 상담 대화 생성.
  - `POST /api/summarize`: 대화 종료 후 10가지 필수 항목 기반의 보고서 생성.

## 4. 상담 흐름 및 AI 로직

### 대화형 상담 (Conversational Chat)
- 기존의 딱딱한 질문지 방식 대신, Gemini 1.5 Flash를 사용하여 학생의 답변에 깊이 공감하며 자연스럽게 다음 정보를 유도합니다.
- **시스템 프롬프트**: '따뜻한 상담사' 페르소나를 부여하고, 대화 중 자연스럽게 10가지 필수 정보(일시, 장소, 가해자 등)를 파악하도록 지시합니다.

### 위험도 판단 및 요약
- 대화 종료 시 LLM이 전체 로그를 분석하여 위험도를 4단계(낮음, 보통, 높음, 긴급)로 분류합니다.
- 관리자에게 제공되는 보고서에는 신체 피해, 반복성, 온라인 연루 여부 등이 체계적으로 정리됩니다.

## 5. 데이터 정책
- **저장**: 현재 MVP 버전에서는 브라우저의 `localStorage`를 사용하여 상담 기록을 영구 보관합니다.
- **개인정보**: 실명은 요구하지 않으며 별명으로 시작하되, 상담 과정에서 학생이 자발적으로 입력한 경우에만 저장됩니다.
- **관리자 접근**: 단일 비밀번호 기반의 인증을 거쳐야만 상담 기록에 접근할 수 있습니다.

## 6. 향후 확장 계획
- 실제 DB(Supabase, Firebase 등) 연동을 통한 데이터 통합 관리.
- 상담 교사용 실시간 알림 시스템(이메일, 슬랙 등).
- 다국어 지원 및 음성 상담 기능 추가.
